# Buscadis

Buscadis es el núcleo del ecosistema ADIS: un marketplace de oportunidades pensado para Latinoamérica.

## Enfoque

- Clasificados con arquitectura Next.js orientada a SEO y performance
- Backend con Supabase para datos, auth y operaciones
- Integración con páginas de negocio en Publicadis y networking en Conectadis

## Rol

Como fundador técnico diseñé el producto, la arquitectura y el ciclo de ship continuo hacia producción.
