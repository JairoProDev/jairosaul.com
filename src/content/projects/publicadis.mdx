# Publicadis

Publicadis es la capa de publicación del ecosistema ADIS: sitios y catálogos para negocios, sincronizados desde un monorepo de clientes.

## Qué resuelve

- Publicación rápida de presencia web
- Hosting centralizado con rutas por negocio
- Conexión con Buscadis para descubrimiento
